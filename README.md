# YieldNest

**Secure today. Funded tomorrow.**

Premium corporate website + owner/admin dashboard starter.

## Structure
- `frontend/index.html` — public landing page
- `admin/index.html` — owner dashboard prototype
- `shared/styles.css` — shared premium design system
- `shared/config.js` — app configuration
- `.env.example` — future backend environment placeholders
- `SECURITY.md` — production security checklist

## Important
This starter is demo software. Before accepting real customer money, implement and independently review applicable legal/regulatory requirements, KYC/AML, payment/custody controls, authentication, authorization, audit logging, security controls, disclosures, and data protection.
