# Security

Before production:
- Use HTTPS everywhere.
- Implement secure authentication and MFA for owner/admin accounts.
- Enforce server-side authorization; never trust frontend permissions.
- Encrypt sensitive data at rest and in transit.
- Use secure secrets management; never commit credentials.
- Add immutable audit logs for financial and administrative events.
- Add rate limiting, monitoring, backups and incident response.
- Complete independent penetration/security testing.
- Implement applicable KYC/AML, privacy, payment and custody controls.
- Obtain jurisdiction-specific legal and regulatory review before accepting real customer funds.
